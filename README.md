# 🌱 EcoMap - Rastreamento

Site desenvolvido para exibir pontos de coleta de pilhas, utilizando geolocalização, mapa interativo e listagem dinâmica dos locais mais próximos.

---

## 📌 Sobre o Projeto

O EcoMap foi criado com o objetivo de facilitar a localização de pontos de coleta de pilhas, contribuindo para o descarte correto de resíduos e para a conscientização ambiental.

Inicialmente, o projeto utilizava PHP, MySQL e phpMyAdmin para carregar os pontos de coleta. Posteriormente, foi adaptado para utilizar um arquivo JSON, tornando o projeto mais simples de hospedar e compatível com plataformas como Netlify e GitHub Pages.

## 🚀 Tecnologias Utilizadas

---

## ✨ Funcionalidades

- Exibição de pontos de coleta de pilhas
- Mapa interativo com Leaflet
- Geolocalização do usuário
- Cálculo aproximado de distância até os pontos
- Ordenação dos pontos mais próximos
- Link para rota no Google Maps
- Cards dinâmicos carregados por JSON
- Menu hamburguer
- Layout responsivo
